在IT公司的生态，项目管理（PM）是一种非常特殊的存在。无法编写代码，无法测试，无法部署，但拥有一项团队中无人能及的超级能力：跟客户交流。

而这正是世间所有痛苦的根源。

因为每次 PM 和客户聊完天，就会带着灿烂的笑容回到团队里，然后抛出一句比电影里的跳吓还要惊悚的话:

“我有很小的变更。“

我团队的PM叫雄。姓阮。河内纸桥区人。领英简介上写着：“敏捷方法爱好者 | 认证Scrum Master | 热情于传递价值。”

传递价值。他唯一始终如一传递的价值，就是在冲刺最后一天给整个团队带来新的需求。

雄哥有一个特点：他喜欢开会。喜欢到如果哪一天没有任何会议，他就会自己创造一个会议。他把这个会议叫做“五分钟快速同步”。他的同步会从来没有少于45分钟的。他这个Scrum Master同步起来就像Windows XP时代的HDD - 转个完不了。

他还有一个毛病：当客户理解 需求，他常常说：“我知道了”。其实，他不懂，他只知道客户在说。内容方面呢，他就留给团队自己去领悟。他称之为“给团队赋能”。团队则称之为“扔完炸弹就跑”。

阿达已经改修好了。

第十五个冲刺，最后一天。周五。下午2点。只有3小时会跟客户做冲刺评审。

阿达刚修完最后一个bug。庄姐刚把API部署到staging环境。坚（运维）刚检查完流水线 一片绿。香姐（QA）刚关闭了最后一个工单。整个团队松了一口气。这个冲刺稳了。可以早点下班。可以喝啤酒。可以像正常人一样生活了。



但阿雄进来。

笑容这么灿烂。

“各位团队成员，我刚和客户通了电话”。

整个团队被冷冻。就像你正在执行 git push --force，然后突然发现自己 push 错了 main 分支时的那种凝固。

“只想加一个小功能。细细小的。大概1-2小时可能完成。“

细细小的。

在IT行业史上，还没有哪句话比“大概一两个小时就能搞定”更具毁灭性了。这句话毁掉的 冲刺 比技术债还多。这句话毁掉的周末比 rm -rf 命令还多。它比低薪水更多程序员辞职。

阿达问：“什么功能？“

“客户要一个省份城市的下拉菜单...“

整个团队打了个寒颤。那个下拉菜单。又是那个下拉菜单。这个从冲刺14就被诅咒的下拉菜单。

“……再加个搜索功能。输入‘Hà’就显示‘Hà Nội’（河内）、‘Hà Giang’（河江）、‘Hà Nam’（河南）、‘Hà Tĩnh’（河静）。很简单的嘛。”

很简单。

阿达在心里默默估算：加搜索输入框、筛选逻辑、加防抖避免每次按键都调API、高亮匹配的文本、处理用户输入不标音越南语时的边界情况、处理无搜索结果时的显示……

“雄哥，这个功能不可能只花的一两个小时”

“啊？只加个搜索框而已吧。“

只加个搜索框而已吧。

这话就相当于房子都盖好了、刷好了、家具都摆好了、人都搬进去住两周了，然后说“不如加个卧室嘛”。

庄姐发言了：“现在的 API 不支持搜索，必须新写一个接口，加查询参数，给数据库加索引。更别说还得做性能测试，省市表里有一万三千多条街道和乡社的记录。”

雄哥说：“好的……那你估算一下，如果做这个任务需要多长时间？”

庄姐说：“3天“

“什么，3天？？？“

“是的。3天。如果没有bug. 但是常常会有bug”

雄哥回头问阿达：“前端呢？“

“两天。必须处理搜索的用户体验、防抖、越南语变音符号匹配、无结果状态..."

“防抖是什么？“

项目经理问“防抖是什么”，像将军在战争中问“用剑干吗？“。哥，你的Scrum证书是在哪儿考的？Lazada(越南的闲鱼)上买的吗？

坚（运维）插话道：“但如果加新接口，我就得更新API网关、加路由、给搜索接口配置限流，因为用户可能会spam。更别说staging环境现在正跟其他团队共用，我还得预约部署时段。”

香姐（QA）说：“而且我得重写测试用例。旧的下拉菜单有12个用例。加上搜索的话至少再多30个。还不算回归测试。”



阿雄沉默了10秒钟。那种刚刚意识到自己向客户承诺了一件团队需要5天才能完成、而现在只剩3小时的事情的沉默。“可是……我已经跟客户说了这个冲刺会有。”整个团队都盯着阿雄。

那种眼神不是愤怒。也不是失望。那是四个人刚刚听到了自己周末的死刑判决书时的眼神。



阿达打开 Slack 私聊庄姐：“今晚肯定留下来加班吧。”

庄姐回：“我知道。周六我约了跟我妈吃饭。”“取消吧。“

”你帮我取消啊。你打电话跟她说‘我忙着修下拉菜单’看她什么反应。”

坚在开发小群（没有PM）里发消息：“阿雄又乱承诺了。这次我建议全队罢工。”

香姐：“罢工完谁给我付房租啊？”

坚：“那您先测着。我来部署。”

“部署什么？代码在哪儿呢？”“那就等那俩写完代码呗。”

“那俩正吵着谁先写呢。”



下午5点。冲刺评审会。客户进入了 Google Meet。

阿雄-以他作为久经沙场的PM的魄力-开场道：“这个冲刺，团队已经按计划出色地完成了所有用户故事。关于省份城市搜索功能，团队经过深入分析，认为需要更多时间来确保用户体验的最佳质量。我们建议将其放入下一个冲刺。”

阿达在下面闭麦，在Slack上敲道：“翻译：我乱承诺了，团队没赶出来，申请延期。”

庄姐回：“但得承认他说得真好听。我说同样的话，客户就骂，他说客户就点头。”

坚：“这就是他工资比你高的原因。”

香姐：“这也是我想转行的原因。”客户点头：“OK，那就下个冲刺吧。不过我还想再加一个东西……”

整个团队第二次凝固了。“……省份城市的下拉菜单，选完之后，能不能顺便显示位置地图？”



地图！



阿雄转头看着镜头里的团队。团队也看着他。八只眼睛，一眨不眨。那是四个士兵刚听到将军说“我们再打一仗吧”，而此刻弹药已尽、粮草已绝、援军正在休假时的眼神。

阿雄咽了口唾沫。然后露出了笑容。“好的，让团队评估一下。”



评估。PM词典里最美的词。它的意思是“我还不知道能不能做，但我不想当着客户的面说不”。



下午六点。客户退出了Meet。整个团队留了下来。

沉默了30秒。



然后坚开口了：“我辞职。”

庄姐：“我也辞。”

阿达：“我比你们俩先辞。”

香姐：“我从冲刺7就在脑子里辞职了。”

阿雄：“大家冷静。我会跟客户重新商量范围。地图可以放第二阶段。搜索下拉菜单下个冲刺时间肯定够。”

“您说‘肯定’的样子，就跟您下午2点说‘大概一两个小时’时一模一样。”

阿雄笑了。那种知道自己错了，但因自尊和Scrum Master的头衔不允许承认的人的笑。



但最后，整个团队还是留了下来。

不是因为爱公司。不是为了怕PM.不是为了什么崇高责任。

因为阿雄外卖了。

2份越南牛肉米粉、1份炒饭、1份河粉、4杯奶茶。总账单487千越南盾。阿勇用公司卡付了。这是PM最重要的技能——知道什么时候该叫外卖，让团队不会造反。阿达一边吃牛肉米粉一边写搜索组件的代码。庄姐一边吸溜河粉一边写API接口。坚一边喝奶茶一边配置API网关。香姐坐着写测试用例，时不时瞥一眼阿达的屏幕，然后记下阿达还没想到的一个边界情况。



阿雄不会写代码。但他留了下来。他又煮了咖啡。他每30分钟问一次“大家需要什么吗？”。他更新Jira面板。他把需求写得更清楚了-15个冲刺以来的第一次。晚上11点。搜索下拉菜单在staging环境跑起来了。



阿达测试了一下：输入 "Hà" → 显示 "Hà Nội"（河内）、"Hà Giang"（河江）、"Hà Nam"（河南）、"Hà Tĩnh"（河静）。输入不带声调的 "ha" → 仍然显示。输入 "hna" → 显示 "未找到结果"。

"不错。"

庄姐检查 API 响应时间：47毫秒。低于100毫秒。可接受。

"不错。"

坚检查服务器日志：没有错误。缓存清除正常。

"不错。"

香姐运行了30个测试用例：29个通过。1个失败 - 当用户在搜索框输入表情符号时应用崩溃。

"谁会拿表情符号搜索省份啊？"- 阿达说

"会有的。相信姐。"- 香姐回答香姐说得对。

QA永远是对的。因为QA像用户一样思考 - 而用户就是疯了。



阿达花了5分钟修复表情符号的边界情况。重新测试。30/30通过。

“上线？”

“上线。”

坚部署到生产环境。周五晚上11点47分。整个团队盯着监控仪表盘。没有报错。没有峰值。一片绿油油。



没人说话。只听见阿达吸溜最后几口已经凉透的牛肉米粉的声音。



午夜12点。整个团队下班回家。阿达骑摩托车，载着庄姐因为都往龙边桥方向。庄姐坐在后座，打开笔记本电脑架在车箱上，敲下最后一条提交信息：“feat: 添加省份搜索接口 - 献给冲刺15的幸存者们。”



坚坐Grab（越南人平常使用的滴滴）回家。车上，他打开手机看到朋友的信息：“嘿明天去喝酒不？” 他回复：“明天我睡觉。补三个冲刺的觉。”



香姐回到家，丈夫问：“怎么回来这么晚？” 她回答：“修下拉菜单。” 她丈夫是做建筑的，看了她5秒钟，没懂下拉菜单是什么，但点了点头然后去热饭了。好男人不需要懂代码。只需要知道在合适的时候热饭。



阿雄回到家，打开领英，发了一篇帖子：

"Proud of my team! Another successful sprint delivery. Teamwork makes the dream work"

47个赞。12条“Congrats！”的评论。没有一条评论来自团队。



下周一， 第十六冲刺的计划会议。

阿雄开始：“这冲刺客户要在地图里加下拉菜单……“

四个人看着他。

“但是我已经商量过，他会在第二阶段。这冲刺我们只要。。。“

整个团队屏住呼吸。“……给整个应用加上深色模式。”



深 色 模 式。



阿达：“哥，你知道深色模式得换整个颜色系统、创建主题提供器、所有页面UI都要重新测试吗？”

“嗯，但客户说很简单嘛。就把白的换成黑的就行。”

就 把 白 的 换 成 黑 的。

庄姐转向阿达：“你的‘证据’文件夹还空着吗？”

“有的，我刚创造子文件夹：'Sprint_16'."

坚打开终端，敲了一行命令然后enter：echo "我爱IT行业" >> lies.txt

香姐没说话。她打开Jira。新建了一个史诗。史诗名称：“深色模式。”然后她创建了第一个工单：“测试：验证应用在1秒内切换主题500次不会崩溃。”

阿达看着这个工单：“谁会在1秒内切换主题500次啊？”

香姐看着他：“会有的。相信姐。”



人生在世做开发，处处都是坑。只可惜…… PM依然通过Zalo（越南的微信）语音消息发来需求。冲刺16开始了。而那个省份城市的下拉菜单，依然萦绕在团队的梦境里。

（END -  除非 PM又给客户打了电话，然后带着灿烂的笑容转身回来。）
